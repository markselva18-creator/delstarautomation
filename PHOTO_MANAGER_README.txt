DELSTAR BROWSER PHOTO MANAGER
============================
1. Extract the complete website ZIP into a folder on your Windows computer.
2. Double-click photo-manager.html in Chrome or Edge.
3. Click Choose File and select projects.html from the same website folder.
4. Choose a project in the dropdown.
5. Click Add photographs to select one or more JPG, JPEG, PNG, WebP or GIF photos.
6. Use left/right arrows to reorder images; click Remove to exclude images from that gallery.
7. Click Export website update ZIP.
8. BACK UP your current projects.html. Extract the exported DelStar_Gallery_Changes.zip INTO YOUR WEBSITE ROOT folder. Confirm replacement of projects.html and addition of images/gallery_... files.
9. Refresh projects.html to view the updated gallery. If the site is online, upload the modified projects.html and the newly added images folder files to your hosting account.

NOTES:
- This is a local browser-based editor. It does not directly modify files on disk or your live hosting account.
- The manager exports only changed files; do not replace your whole website with the changes ZIP.
- Existing images are referenced by their original filenames and are not copied into the changes ZIP.
- Removing an image from a gallery does not delete its original file.
- First image in each gallery becomes the project tile cover.
- Keep photo-manager.html and css/photo-manager.css and js/photo-manager.js together in their original relative paths.
- For subsequent edits, always load the latest updated projects.html, not an older copy.
- No Python, database, external library or internet connection is required.
