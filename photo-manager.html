DelStar Project Photo Manager

Manage project galleries visually. No Python, server, or HTML editing required.

This manager works offline. Your original website files are never changed until you apply the exported update.

Select projects.html to begin.

Use the arrow buttons to reorder. Remove hides a photo from this gallery; it does not delete the original image file. First photo becomes the project tile cover.

3. Apply your update

After exporting, extract the ZIP into your DelStar website folder, allowing projects.html to be replaced and new photographs to be copied into images/. Keep a backup first. Upload those changed files to your hosting provider if the website is online.

The exported ZIP contains only changed website files, not the entire website. No images are uploaded to any server by this manager.
